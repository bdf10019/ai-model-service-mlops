# AI 模型服務與 MLOps｜獨立互動介紹網站

這是產品 0.4.1 的離線作品介紹站，網站版本為 1.1.0。網站以 `EQ-PUMP-001` 循環水泵串起維修與設備管理兩種工作方式，並以隨附資料和去識別截圖呈現既有能力；客製化、發布、回滾與人工複核互動只修改目前瀏覽器的展示狀態，不呼叫控制台 API。

## 啟動

三作品合輯展示建議從工作根目錄執行中央腳本；它會先驗證連接埠上的網站標題，正確網站會沿用且不取得停止權：

```powershell
.\2026_10月合輯\scripts\showcase.ps1 -Action Status
.\2026_10月合輯\scripts\showcase.ps1 -Action Start
```

完整停止規則與常見問題見 `2026_10月合輯/docs/展示啟動與復原手冊.md`。

在產品工程版目錄執行：

```powershell
.\scripts\start_showcase.ps1
```

瀏覽器開啟 <http://127.0.0.1:4178/>。此入口只綁定本機。網站完成一次依賴準備與建置後，不需要網路、GPU或 8120 控制台。

重新示範：重新載入此頁即可清除本站記憶體內的互動狀態；不會清除帳號、控制台或其他瀏覽器資料。

若尚未安裝網站依賴，先執行：

```powershell
.\scripts\prepare_showcase.ps1
```

## 驗證

```powershell
.\scripts\verify_showcase.ps1
```

它會重新產生白名單資料、檢查資料隱私、建置網站、執行互動測試與桌面／手機端對端驗收。控制台入口 `http://127.0.0.1:8120/` 只供訪客主動點選；介紹站不探查它是否存在。

## 證據邊界

- `歷史實測`：來自既有版本化報告的白名單投影。
- `合成示範`：解釋狀態與規則的本機互動，不是新推論或新發布。
- `限制`：尚未完成、未提供或不可外推的項目。
- 三組品質資料均已觀測；沒有獨立專家標註，也不能代表真實工廠泛化。
- `public/data/pump-demo-regression-v1.json` 是離線展示回歸案例，不是模型評測、保留集或品質證據。
