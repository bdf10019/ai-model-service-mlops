## 輸入、輸出與執行身分

輸入／輸出均拒絕未知欄位；事件 8–1600 字元，設備編號限定 3–64 個 ASCII 字元，補充欄位為封閉枚舉。輸出八項核心欄位是 event_type、severity、summary_zh_tw、evidence_spans、missing_information、safe_actions、review_required、reason_codes。

目前 Prompt 是本產品原創 `triage-service-v1`／`triage-asset-v1`，Schema `triage-v1`，安全底線 `safety-floor-v1`；不能將其測試與八月 optimized-v2 成績直接視為相同契約。模型指標分開保留 raw_output 與政策後 result。

每個任務保存實際 Profile 快照與 hash、Prompt／Schema／policy 版本、模型 hash、輸入內容的不可逆身分 hash、執行參數與真實事件。一般原文及完整結果不寫入 DB；合成樣本需與版本化範例的全部欄位逐字匹配，偽造 sample_id 不會取得持久化資格。

實測固定參數為 temperature=0、seed=42、max_tokens=256、context=4096、parallel=1、GPU layers=all，未請求串流。Token 使用量來自引擎回應；TTFT 記 null。

權重及 binary 忽略於 Git。保有來源者可用 `scripts/import-local.ps1` 在新目錄複製相符產物，腳本禁止覆寫既有目標並執行 manifest 核對；沒有來源者仍可用 Fixture 測控制台。新的下載、換模或大檔取得需另行確認。
