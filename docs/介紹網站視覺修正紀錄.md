# 介紹網站視覺修正紀錄

本輪依據：使用者指出效果不理想，以及上一輪 Chrome 實際畫面。此文件記錄視覺修正，不取代原有品質報告或模型發布狀態。

## 從實際畫面與程式核對的問題

1. 政策後人工負擔沒有對應按鈕樣式，出現瀏覽器預設灰框、藍色進度條，指標與分母擠在一起。
2. 原始／政策後比较將箭頭放進等寬三欄，中間出現不合理空白。
3. 首頁統計列位於兩欄布局內，但未跨欄，造成第四個數字被擠壓。
4. 複核內容使用 article，原樣式只選取 div，所以三張卡片的外框與底色未生效。
5. 淺色頁面使用了白字頁籤樣式；發布區白色卡片繼承白字，對比不足。
6. 流程頁籤以 aria-selected 標示狀態，但原樣式判斷 aria-pressed，選取樣式沒有生效。
7. 平板寬度 761–1050px 隱藏導覽連結，但尚未顯示手機選單。
8. 部分箭頭被當成等寬內容欄，造成架構與 A→B→A 排版斷裂。
9. 中文標題尺寸與行距造成難讀斷行；舊截圖只縮成極長全頁，未充分檢查每個可視區域。

## 已修改

- 重整字級、行距、留白、卡片、表單、深浅色背景與互動狀態。
- 首頁加入既有去識別真實控制台截圖，點選可放大；合成切換仍標示其性質。
- 首頁統計完整跨欄；手機改成兩列。
- 複核三欄套用正確樣式；人工負擔改成完整寬度的指標列。
- 原始／政策後使用「內容／小箭頭／內容」布局，移除中間的大空白。
- 發布步驟、回滾流程、頁籤與導覽選取狀態有清楚對比。
- 1150px 以下啟用可展開導覽，手機卡片與表單維持單欄。
- P50／P95 改用兩條長條與固定刻度，併發切換沿用相同尺度，沒有把分位數畫成時間趨勢。
- 保留歷史分子／分母、候選未發布、h15 退步與 TTFT 未提供。
