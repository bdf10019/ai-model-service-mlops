# 操作與安全邊界

評測／核准／發布操作見 [客製化與發布走查](客製化與發布走查.md)；0.3.0新增監控／負載／告警／MLflow見[維運手冊](可視化維運與操作手冊.md)，資料備份見[安全契約](備份還原與交付契約.md)。本頁保留共同安全與資料留存邊界。

## 日常操作

1. 啟動控制台，設定第一位管理者並登入。
2. 到帳號頁建立一般使用者及複核者；用個別帳號登入驗證權限。
3. 模型頁執行產物核對／啟動候選引擎，完成後刷新健康。
4. 頂列選團隊設定；Playground 主動選真實 Q8 或 Fixture。
5. 選合成範例或輸入事件，補必要欄位後提交。
6. 詳情顯示排隊、生成、驗證及完成／複核／失敗；比較原始模型與安全政策結果。
7. 任務頁篩選、鑽取及取消排隊工作；Trace 頁探索事件與版本。

頂列切換 Profile 不改登入角色，不修改舊任務快照。角色控制在後端，不只是隱藏按鈕。管理者登入後可建立帳號及控制候選引擎；operator 只看自己的工作與稽核，reviewer 可探索同一安裝的授權工作，不能控制引擎。

## 暫存、持久化與秘密

SQLite 存使用者 scrypt 密碼雜湊、雜湊 session token、有限期限與 CSRF 隨機值。帳號清單不回傳雜湊或憑證，表單驗證錯誤不回顯 input/context。沒有公用預設密碼。

一般請求只在記憶體持有文字，完整輸出也僅暫留 15 分鐘、最多 100 筆，期滿讀取或後續提交時清理。此期限是讀取資格期限，不承諾作業系統記憶體的安全抹除。資料庫只保留版本、狀態及不含原文的結果摘要。完整文字不寫應用程式日誌。

官方引擎的診斷紀錄存於 Git 忽略的 state 私有紀錄，不由產品 API 提供；可能包含本機環境細節，不能當公開報告。原創合成案例可存 raw／result，來源欄位必須全匹配才可保存。重整及重啟仍能讀取合成結果，一般記憶體結果在服務重啟後不再存在。

測試與證據暫放 reports／tmp，皆忽略於 Git。隱私掃描目前針對可交付原始碼的有限模式，不掃描或自動公開私有運行資料，不能稱完整個資辨識或 CVE 稽核。

## 安全及失敗

- 本機 loopback 服務，Host 白名單、同源 Origin、非簡單請求標記及 session CSRF。無 CORS，不允許任意外部 URL／代理轉送。
- 控制端 JSON 實收大小上限 32 KiB、讀 body 有界時間；引擎回應解碼後大小上限 256 KiB。
- 原文證據必須存在於輸入，錯證據移除並強制複核；風險只升級，危急／高風險採確定性升級代碼。注入、unknown、無證據強制複核。模型未通過 Schema 或被截斷時整筆失敗，不偽造正式結果。
- 平台一個容量槽；兩 Profile 共用有限等待區。等待到期的工作不執行；拒絕有 Retry-After。生成逾時後仍保留槽直到引擎工作真正結束或本作品引擎停止。
- 只允許取消尚未開始的推論；同步生成無安全取消能力，UI 清楚說明。
- 重啟將中斷狀態 reconcile 為 SERVICE_RESTARTED，不自動重播；任務可查原因但尚無一鍵重試入口，需從 Playground 主動另建請求。
- 停止只處理自己啟動的引擎與子程序，不接管或停止其他模型服務。

## 未交付邊界

0.2.0 已提供固定評測、品質門檻、獨立單／雙核准、真實服務設定發布／回滾／恢復，以及設定／合成證據匯出。流程與限制見 [版本治理](版本治理與架構.md)。沙盒候選不直接改已發布版本，設定編輯不影響舊任務；發布與回滾繁忙時拒絕，失敗不能顯示成功。

0.3.0新增有界本機負載、互動監控、本機告警、按需MLflowSQLite同步與安全業務隔離還原，後端有資源／角色／格式／完整性限制。備份排除秘密／登入／私人原文，沒有正式active權威搬遷；MLflow參照不取代發布資料庫。

尚無人工結果批准、不同權重切換、全域限流、多副本、企業IAM、TLS公網部署、MLflow Model Registry、Prometheus server、全量sealed證據包或完整災難復原。服務發布核准不是實體設備處置許可。新保留集揭露安全層對否定敘述可能過度升級，不因保留安全底線而忽略品質缺口。

目前沒有逐 Token 串流，所有 TTFT 明示未量測。本機 append-only 稽核沒有外部簽章或不可變儲存；不同 Profile 不是租戶隔離。


0.4.0：人工複核與來源留存見[複核手冊](判讀品質與人工複核手冊.md)。預設一般原文15分鐘記憶體；明確勾選同意的待複核來源可本機7日，限100筆，排除備份／公開匯出。人工輸入摘要、理由與最終結果另存本機，可能含使用者自填私人內容，不上傳。人工處理不改原始推論或模型發布；所有設備動作仍不执行。

0.4.1釐清「保存期間不可覆寫」不等於永久保存，並實際清理到期來源、由後端阻擋缺來源複核。原始證據仍排除備份；人工摘要／理由／修正／歷史與業務政策可由admin先預覽、明確確認後匯出專用業務備份，其中仍可能含私人資料。還原只建立新隔離安裝，資料唯讀、無來源、帳號或發布權威，不能重新批准或作模型發布證據。完整範圍見[複核資料生命週期與備份契約](複核資料生命週期與備份契約.md)。
