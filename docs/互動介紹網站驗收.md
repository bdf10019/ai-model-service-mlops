# 獨立互動介紹網站驗收

日期：2026-09-24  
介紹網站版本：1.0.1  
對應產品版本：0.4.1  
結果：A～E 完成，本機可交付

## A｜內容、分鏡與資料白名單

- 完成九章資訊架構、30 秒首頁、三分鐘產品路徑及六分鐘工程證據路徑。
- 建立桌面與 390px 手機分鏡；手機改用可展開九章導覽、單欄內容和可橫向操作的流程列。
- 白名單只投影三組品質資料的分子／分母、四筆代表案例、兩組負載摘要、測試計數及來源 SHA-256。
- 六張產品截圖來自隔離測試資料，已人工檢視；文字投影通過敏感欄位與明顯秘密掃描。

## B｜網站與互動流程

- 完成 React／TypeScript／Vite 獨立網站，所有程式、資產、依賴鎖定檔、測試和輸出都位於第一個作品內。
- 可在不啟動控制台、不使用 GPU、不連網的條件下瀏覽九章、操作合成示範和閱讀歷史證據。
- 維修與設備 Profile 會改變欄位、推論參數、複核範圍、理由、核准、佇列與告警門檻；設備缺欄位會顯示錯誤並阻擋預覽。
- 發布重播最終維持 triage-v5／v5.1 未發布；回滾明示為同一 Q8 的服務設定 A→B→A。
- 人工結果另列，設備流程需要兩次確認；修正理由及證據參照有 Profile 對應驗證。

## C｜證據與下載

- 三個品質資料版本均可切換 raw／post，展示分子、分母、生成數、安全違規、延遲與人工負擔。
- h03、h08、h11 顯示政策缺陷修正，h15 保留原始輸出退步，未以人工結果美化模型正確率。
- 歷史負載以併發 1／2 和排隊／引擎生成維度比較；TTFT 明示未提供。
- 提供可列印 HTML、Markdown 作品摘要與去識別 JSON 證據摘要。沒有公開整個 reports 目錄。

## D｜視覺與手機精修

- 完成原創 MODEL SERVICE 文字標誌、米白／深綠／琥珀視覺、完整段落階層、空間與互動焦點。
- 首頁最前方新增零經驗訪客說明，以設備異常、人工確認、版本切換與復原解釋產品；採琉璃通透與低飽和彩虹流光，列印及降低動態偏好時改為靜態。
- 全站可見文字在桌機精細指標下提供最大 3.5px 的靠近微排斥，滑鼠離開即還原；按鈕、連結和表單的命中區不移動，觸控與降低動態偏好不啟用。
- 使用系統字型與隨附 SVG／PNG，沒有外部 CDN。
- 390×844 驗證沒有橫向溢位；導覽、表單、頁籤、流程重播、截圖燈箱及下載入口都可操作。
- 支援鍵盤焦點、Skip Link、Esc 關閉燈箱、降低動態偏好與列印樣式。
- 依 Chrome 實際首頁畫面重新檢查文字對比、首屏層級與版本；桌面及手機整頁驗收圖由自動化重新產生。

## 展示路徑

### 三分鐘：產品決策

1. **0:00–0:30** 首頁：用途、主要訪客、離線／實測標籤、0.4.1 狀態。
2. **0:30–1:20** 客製實驗台：切設備版，先觸發必填錯誤，再完成預覽；指出七項實際差異。
3. **1:20–2:10** 發布與回滾：重播四步，解釋不合格候選為何停在發布前。
4. **2:10–2:40** 人工複核：示範雙人確認或另存人工修正，指出原始輸出不覆寫。
5. **2:40–3:00** 開始使用：說明 8120 是訪客本機入口，展示三種摘要下載。

### 六分鐘：工程證據

1. **0:00–0:45** 首頁與情境：已恢復、資訊不足、高風險如何分流。
2. **0:45–1:45** 客製實驗台：欄位／參數／複核／核准／監控政策的版本化差異。
3. **1:45–2:30** 七步流程：角色、產物契約、任務啟動版本與後端安全邊界。
4. **2:30–3:15** 發布／回滾：品質封鎖、active／previous 與同一 Q8 設定回滾。
5. **3:15–4:05** 人工複核：raw／post／human 分離、保存期限、Profile 流程差異。
6. **4:05–4:45** 維運：併發 1／2 的 queue、generation、吞吐；解釋 TTFT 缺口。
7. **4:45–5:40** 品質：切三組資料、raw／post、h03 與 h15，說明人工負擔及退步。
8. **5:40–6:00** 真實畫面、限制、下載與本機控制台入口。

## 已知限制

- 介紹站的互動是固定合成重播，不代表執行新的推論、負載、發布、回滾或資料寫入。
- 三組品質集均已觀測，資料為小型 AI 合成標註；沒有獨立專家或真實工廠泛化驗證。
- triage-v5／v5.1 未通過發布條件；triage-v4 只可稱既有回歸基線。
- Logo 自訂與首頁自由布局只屬介紹站視覺及規劃狀態，尚未成為控制台功能。
- 原產品仍缺 Docker／WSL 實跑、Model Registry、真正逐 Token 串流、相容端點、不同權重切換與公開部署驗證。
- 介紹網站未對外發布；這次驗收只涵蓋本機啟動與靜態建置。
- 文字微排斥屬視覺回饋，不表示即時資料或模型運算；為維持可用性，觸控裝置與降低動態偏好會停用。
