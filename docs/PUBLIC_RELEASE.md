# 公開交付契約 / Public release contract

日期：2026-10-10。AI Model Service & MLOps｜AI 模型服務與維運治理 的公開來源副本。

## 來源與同步

本機正式版不就地改成發布目錄。GitHub 公開版使用獨立乾淨目錄，只匯出目前需要的來源與素材，不推送本機舊 Git 歷史。核心程式、測試、Schema、設定模板及 showcase 公開資料保留；README、忽略規則及此交付文件為公開版補充。後續更新須先掃描與驗證，不能把本機工作根目錄直接 git add。

## 可公開與排除

公開：原始碼、依賴鎖檔、合成資料契約、已去識別展示摘要、必要自製素材與第三方授權文件。排除：帳號／密碼／Cookie／Session、CSRF／API Token、SQLite、state、tmp、原始複核／工單／上傳文件、備份、reports 整包、模型權重、引擎 binary、依賴安裝、建置產物及私人機器路徑。

公開摘要只能表明歷史驗收，不是新的真實模型成績。合成測試身分／固定測試密碼不代表正式帳號。介紹站資料是瀏覽器內示範，不具核心產品核准或發布權威。

## 建置與發布邊界

原始碼公開到 GitHub；本輪不啟用 Pages、雲端 API、GPU 或遠端核心服務。依 README 在自己的本機建置，對應埠需自行啟動。以原鎖檔準備依賴；當次驗證可重用現有套件快取和 Python 環境，但來源／測試狀態在此公開副本，不回寫正式資料。沒有重新下載模型或執行真實 GPU 品質評測。

此副本不含全部歷史報告，原操作文件中的私有 reports 連結僅供本機上下文，不保證公開可點擊。公開的固定摘要隨 showcase 提供；證據產生器需要原歷史報告時不假造輸入。當次公開交付摘要見 PUBLIC_VERIFICATION.md。
