## 真實發布與回滾證據

透過實際產品介面，維修 A 核准／發布 → 新推論 320／42 → B 重評／核准／發布 → 新推論 384／84 → 回滾 A → 新推論 320／42。每個切換含兩筆實際 Q8 探針，任務 completed 才承認成功；新請求 release_id／設定 hash 與實際引擎參數符合。候選 B 保留，沒有只改標籤。

設備另實跑評測、不同兩名 reviewer 核准、維護未確認拒絕及確認後發布／推論；真實參數 384／84，review_rate 80% 相對維修 50%。核准角色、欄位與政策實際不同。

兩服務版共用同一 Q8 model SHA-256：`d4729ea11ea540d46be45effe7b41ffbe55bc51ce7e42bf7443cd2bbf84ca9ed`。回滾是服務設定版本，不是不同權重。這是獨立測試安裝的真實本機驗收；未把測試核准或帳號灌進使用者既有正式狀態。
